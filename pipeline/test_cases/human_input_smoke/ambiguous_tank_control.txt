A feed valve fills one atmospheric tank. When the operator presses START, the controller opens the feed valve and closes it when the tank level reaches 1.0 m. The simulation shall run for 120 seconds and report tank level and valve state. The tank cross-sectional area is 2.0 m2. The required inlet flow rate is intentionally unspecified; the engineer must ask the user to choose the inlet flow rate before generating the SysML model because it changes the filling time.
