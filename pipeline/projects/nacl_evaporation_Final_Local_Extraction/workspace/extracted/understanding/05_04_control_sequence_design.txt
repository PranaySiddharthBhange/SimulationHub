## Requirements
*   Report tank levels and valve commands for a 900-second experiment (implied duration)
*   LIS-301 >= 0.13 m
*   QI-302 >= 0.080 kg/kg
*   LIS-501 < 0.01 m
*   LIS-501 >= 0.18 m
*   QIS-502 >= 0.180 kg/kg
*   TIS-602 <= 20 degC
*   TIS-702 <= 25 degC
*   time > 2500 s
## Behaviors
*   IF LIS-301 >= 0.13 m THEN V8=OPEN
*   IF QI-302 >= 0.080 kg/kg THEN V9=OPEN
*   IF LIS-301 < 0.01 m THEN V11=OPEN
*   IF LIS-501 < 0.01 m AND NOT V15 THEN No transfer actuator
*   IF LIS-501 >= 0.18 m THEN V12=OPEN
*   IF QIS-502 >= 0.180 kg/kg THEN B5_Heater=ON
*   IF TIS-602 <= 20 degC THEN B6_Cooler=ON
*   IF B6 return complete THEN P2=ON + corrected B1 return valve group
*   IF LIS-701 < 0.01 m THEN No transfer actuator
*   IF LIS-501 < 0.01 m THEN V15=OPEN
*   IF TIS-702 <= 25 degC THEN B7_Cooler=ON
*   IF B7 return complete THEN P1=ON + corrected B2 return valve group
