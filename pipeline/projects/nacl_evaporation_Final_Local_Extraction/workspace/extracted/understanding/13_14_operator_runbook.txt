## Requirements
Report tank levels and valve commands for a 900-second experiment
B3 level rises during water and brine charge, then falls while V11 transfers to B4.
B3 concentration changes primarily while V9 adds brine; then remains approximately constant until discharge.
B5 temperature rises during heating, then plateaus near composition-dependent boiling temperature.
B5 concentration rises during evaporation until target is reached.
B6 level rises as condensate is produced; later falls during return pumping.
B7 level rises when V15 transfers concentrate; later falls during return pumping.

## Behaviors
IF B3 level rises AND B2 contains concentrated NaCl THEN V9 opens.
IF B3 level falls AND V11 opens THEN V11 transfers B3 to B4.
IF B5 temperature rises THEN heating is active.
IF B5 temperature plateaus THEN heating is maintained.
IF B6 level rises THEN return pumping is active.
IF B7 level falls THEN return pumping is active.
