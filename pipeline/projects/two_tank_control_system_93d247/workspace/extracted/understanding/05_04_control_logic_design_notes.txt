## Requirements
* Numeric setpoints and delays shall follow the latest approved parameter/change records. [approved]
* SHUT has the highest command priority. [approved]
* STOP has the next priority. [approved]
* START has the lowest priority. [approved]
* A new START is required after shutdown has completed and the controller has returned to IDLE. [approved]
* When STOP occurs in WAIT_AFTER_FILL, WAIT_AFTER_TRANSFER or WAIT_AFTER_DRAIN, the remaining delay shall be retained. [approved]
* START shall resume with that remaining delay. [approved]
* V1 and V2 shall never be open simultaneously. [approved]
* V2 and V3 shall not be open simultaneously during normal automatic operation. [approved]
* The V2/V3 simultaneous-open restriction is explicitly waived in SHUTDOWN. [approved]
* All valves are de-energize-to-close. [approved]
* Level threshold comparisons shall include equality (>= high, <= low). [approved]
* Formal approval of a small increase in T1 high limit above the 0.78 m URS baseline was pending when Rev B was issued. [proposed]
* Use a later approved change request if available for post-transfer and inter-cycle delays. [approved]

## Behaviors
* A START edge begins FILL_T1 from IDLE. [approved]
* FILL_T1 transitions when LT-101 >= T1_High. [approved]
* STOP freezes remaining time in WAIT_AFTER_FILL. [approved]
* TRANSFER_T1_T2 transitions when LT-101 <= T1_Low. [approved]
* STOP freezes remaining time in WAIT_AFTER_TRANSFER. [approved]
* DRAIN_T2 transitions when LT-102 <= T2_Low. [approved]
* WAIT_AFTER_DRAIN returns to FILL_T1 automatically after inter-cycle wait. [approved]
* PAUSED preserves the interrupted sequence state and, if applicable, its remaining timer; START resumes the stored state. [approved]
* SHUTDOWN remains active until both tanks are at or below their low-level limits, then closes all valves and goes to IDLE. [approved]
* A valid SHUT edge immediately abandons any stored resume context and enters SHUTDOWN. [approved]
* STOP is accepted from any normal running or wait state and places the controller in PAUSED with all valve outputs false. [approved]
* START from IDLE begins FILL_T1; START from PAUSED restores the interrupted state. [approved]
* START while already running is ignored. [approved]
* Commands received while SHUTDOWN is active do not interrupt the shutdown sequence. [approved]
* On controller power loss, output commands shall be false. [approved]
* IDLE with START edge goes to FILL_T1 and sets V1=1. [approved]
* FILL_T1 with LT-101 >= T1_High goes to WAIT_AFTER_FILL and sets V1=0; start timer. [approved]
* WAIT_AFTER_FILL with timer expired goes to TRANSFER_T1_T2 and sets V2=1. [approved]
* TRANSFER_T1_T2 with LT-101 <= T1_Low goes to WAIT_AFTER_TRANSFER and sets V2=0; start timer. [approved]
* WAIT_AFTER_TRANSFER with timer expired goes to DRAIN_T2 and sets V3=1. [approved]
* DRAIN_T2 with LT-102 <= T2_Low goes to WAIT_AFTER_DRAIN and sets V3=0; start timer. [approved]
* WAIT_AFTER_DRAIN with timer expired goes to FILL_T1 and sets V1=1. [approved]
* normal/wait with STOP edge goes to PAUSED with all valves 0 and stores state plus remaining wait. [approved]
* PAUSED with START edge goes to stored state and restores state outputs. [approved]
* any non-shutdown with SHUT edge goes to SHUTDOWN with V1=0,V2=1,V3=1 and clears resume context. [approved]
* SHUTDOWN with LT-101 <= T1_Low AND LT-102 <= T2_Low goes to IDLE and sets V2=0,V3=0. [approved]
