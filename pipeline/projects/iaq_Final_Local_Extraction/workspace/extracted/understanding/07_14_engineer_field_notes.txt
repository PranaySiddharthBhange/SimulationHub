## Entities
*   freshAir.m_flow
*   peopleSource
*   Room
*   Sensor

## Relationships
*   freshAir.m_flow supplies Room
*   peopleSource supplies Room
*   Room contains Sensor

## Requirements
*   Controller bottoms at 0.2 ACH for long unoccupied periods.
*   Sensor-fault fallback is a requirement.

## Behaviors
*   If freshAir.m_flow > 0, then Room IQA increases.
*   If peopleSource > 0, then Room IQA increases.
*   If Room IQA > 996.52 ppm, then Controller adjusts freshAir.m_flow.
*   If Room is unoccupied for a long period, then Controller sets freshAir.m_flow to 0.2 ACH.

## Constraints
*   Kp = 6
*   Bias = 3.5 ACH

## Physical relationships
*   carrier m_flow * 100 = CO2 kg/s

## Control laws
*   Controller adjusts freshAir.m_flow based on the error between the measured Room IQA and a target value (not specified).

## Scheduled commands
*   None

## Scheduled commands
*   New schedule peaks at 15 people after lunch.
