## Entities
*   V: Room volume [m3]
*   rho: Nominal air density [kg/m3]
*   C_nominal: Nominal trace concentration [kg/kg]
*   C_out: STALE: 350 ppm equivalent [kg/kg]
*   GPeo: CO2 generation [kg/s/person]
*   CPeo: Trace concentration used by peopleSource [kg/kg]
*   Kp: STALE controller tuning [ACH/normalized]
*   uBias: STALE ACH bias
*   uMin: 0.2
*   uMax: 6.0
*   nPeo: occupancy, legacy schedule peaks at 12
*   mPeoCarrier: carrier source flow [kg/s]
*   CRoom: room CO2 mass fraction [kg/kg]
*   yCO2: normalized feedback
*   achCmd: ACH command
*   mFreshCmd: negative means into room at source port

## Relationships
*   mPeoCarrier = nPeo * GPeo / CPeo
*   yCO2 = CRoom / C_nominal
*   achCmd = min(uMax, max(uMin, uBias + Kp * (yCO2 - 1)))
*   mFreshCmd = -V * rho / 3600 * achCmd

## Requirements
*   None

## Behaviors
*   ACH command is calculated as `min(uMax, max(uMin, uBias + Kp*(yCO2 - 1)))`
*   Fresh air flow rate is calculated as `-V * rho / 3600 * achCmd`

## Constraints
*   V: Room volume [m3] constrained between 0 and 100
*   rho: Nominal air density [kg/m3] constrained between 0 and 1.2
*   C_nominal: Nominal trace concentration [kg/kg] constrained between 0 and 1.519e-3
*   C_out: STALE: 350 ppm equivalent [kg/kg] constrained between 0 and C_nominal
*   GPeo: CO2 generation [kg/s/person] constrained between 0 and 8.18e-6
*   CPeo: Trace concentration used by peopleSource [kg/kg] constrained between 0 and 100
*   Kp: STALE controller tuning [ACH/normalized] constrained between 0 and 4.0
*   uBias: STALE ACH bias constrained between 0 and 3.0
*   uMin: 0.2
*   uMax: 6.0

## Physical relationships
*   None

## Control laws
*   ACH command is calculated as a proportional control law: `achCmd = min(uMax, max(uMin, uBias + Kp * (yCO2 - 1)))`
