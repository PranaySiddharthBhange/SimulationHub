## Relationships
*   XV-101 supplies command to V1
*   XV-102 supplies command to V2
*   XV-103 supplies command to V3
*   LT-101 depends_on V1 level
*   LT-102 depends_on V2 level
*   V1 controls XV-101
*   V2 controls XV-102
*   V3 controls XV-103
*   V1 is open during FILL_T1
*   V2 is open during TRANSFER_T1_T2
*   V3 is open during DRAIN_T2
*   V1 is closed during WAIT_AFTER_FILL, WAIT_AFTER_TRANSFER, WAIT_AFTER_DRAIN
*   V2 is closed during WAIT_AFTER_FILL, WAIT_AFTER_TRANSFER, WAIT_AFTER_DRAIN
*   V3 is closed during WAIT_AFTER_FILL, WAIT_AFTER_TRANSFER, WAIT_AFTER_DRAIN
*   V1 is closed during IDLE, SHUTDOWN
*   V2 is closed during IDLE, SHUTDOWN
*   V3 is closed during IDLE, SHUTDOWN
*   XV-101 is open during FILL_T1
*   XV-102 is open during TRANSFER_T1_T2
*   XV-103 is open during DRAIN_T2
*   LT-101 triggers transition to WAIT_AFTER_FILL
*   LT-101 triggers transition to TRANSFER_T1_T2
*   LT-102 triggers transition to WAIT_AFTER_DRAIN
*   LT-101 triggers transition to FILL_T1 automatically after WAIT_AFTER_FILL
*   LT-102 triggers transition to DRAIN_T2 automatically after WAIT_AFTER_DRAIN
*   LT-101 triggers transition to FILL_T1 automatically after WAIT_AFTER_TRANSFER
*   LT-102 triggers transition to DRAIN_T2 automatically after WAIT_AFTER_TRANSFER
*   STOP freezes remaining timer
*   START resumes remaining timer
*   SHUT transitions to SHUTDOWN

## Requirements
*   Controller shall transition between FILL_T1, WAIT_AFTER_FILL, TRANSFER_T1_T2, WAIT_AFTER_TRANSFER, DRAIN_T2, WAIT_AFTER_DRAIN, PAUSED, and SHUTDOWN states.
*   Timer durations shall be retained when STOP occurs in WAIT_AFTER_FILL, WAIT_AFTER_TRANSFER, or WAIT_AFTER_DRAIN.
*   START shall resume with the retained timer.
*   Level threshold comparisons shall include equality (>= high, <= low).
*   Experiment duration: 900 seconds (stated in note 8).
*   Report tank levels and valve commands for 900 seconds.

## Behaviors
*   IF LT-101 >= T1_High THEN transition to WAIT_AFTER_FILL, open V1
*   IF LT-101 <= T1_Low THEN transition to WAIT_AFTER_TRANSFER, open V2
*   IF LT-102 <= T2_Low THEN transition to WAIT_AFTER_DRAIN, open V3
*   IF timer expired THEN transition to next state, open appropriate valve
*   IF STOP occurs in WAIT_AFTER_FILL, WAIT_AFTER_TRANSFER, or WAIT_AFTER_DRAIN THEN retain remaining timer and transition to PAUSED
*   IF START occurs in PAUSED THEN restore stored state and outputs
*   IF START occurs while running THEN ignore
*   IF SHUT occurs THEN transition to SHUTDOWN, close all valves
*   IF LT-101 <= T1_Low AND LT-102 <= T2_Low THEN transition to IDLE, close all valves

## Constraints
*   V1 and V2 shall never be open simultaneously.
*   V2 and V3 shall not be open simultaneously during normal automatic operation.
*   V2/V3 simultaneous-open restriction is waived in SHUTDOWN.

## Physical relationships
*   None

## Scheduled commands
*   START command: triggered by START edge from IDLE or PAUSED
*   STOP command: triggered by STOP edge from any state
*   SHUT command: triggered by SHUT edge from any state
*   Timer expiration: triggers transitions to next state

## Scheduled commands
*   START command: triggered by START edge from IDLE or PAUSED
*   STOP command: triggered by STOP edge from any state
*   SHUT command: triggered by SHUT edge from any state
*   Timer expiration: triggers transitions to next state
