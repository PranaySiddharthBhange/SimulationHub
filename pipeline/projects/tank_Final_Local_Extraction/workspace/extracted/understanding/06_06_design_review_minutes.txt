## Requirements
- Report tank levels and valve commands for a 900-second experiment (D-06)
- LT-101 and LT-102 must be at or below their low-level setpoints for SHUT to be complete (D-06)
- After shutdown completion, all valves must be closed and the sequence context reset to IDLE (D-07)
- V1 and V2 must never be commanded open together (D-08)
- V2 and V3 must not be commanded open together in normal auto operation; SHUT is the only permitted exception (D-09)

## Behaviors
IF LT-101 < 0.78 m AND LT-102 < 0.78 m THEN SHUT is complete (D-06)
IF STOP THEN STOP closes V1, V2, and V3 and freezes remaining delay (D-02)
IF START THEN START resumes remaining delay (D-03)
IF START while automatic sequence is running THEN START is ignored (D-04)
IF START or STOP received during active SHUT THEN START or STOP is ignored (D-05)

## Constraints

V2 and V3 must not be commanded open together in normal auto operation; SHUT is the only permitted exception (D-09)
