## Entities
*   A1 (parameter) - 1.20 m2
*   A2 (parameter) - 1.40 m2
*   h0 (parameter) - 0.05 m
*   h1High (parameter) - 0.78 m
*   h1Low (parameter) - 0.05 m
*   h2Low (parameter) - 0.05 m
*   qFill (parameter) - 0.0060 m3/s
*   qTransfer (parameter) - 0.0045 m3/s
*   qDrain (parameter) - 0.0050 m3/s
*   wait1 (parameter) - 10 s
*   wait2 (parameter) - 10 s
*   wait3 (parameter) - 10 s
*   tank1Level (variable) - 0.05 m
*   tank2Level (variable) - 0.05 m
*   valve1 (boolean)
*   valve2 (boolean)
*   valve3 (boolean)
*   startCmd (boolean)
*   stopCmd (boolean)
*   shutCmd (boolean)
*   seq (discrete) - StepState enumeration
*   stopped (boolean)

## Relationships
*   A1 supplies to tank1Level
*   A2 supplies to tank2Level
*   h0 sets initial value of tank1Level
*   h1High sets upper limit of tank1Level
*   h1Low sets lower limit of tank1Level
*   h2Low sets lower limit of tank2Level
*   qFill supplies to tank1Level
*   qTransfer supplies to tank2Level
*   qDrain supplies to tank2Level
*   wait1 duration between states
*   wait2 duration between states
*   wait3 duration between states
*   valve1 controls flow into tank1Level
*   valve2 controls flow into tank2Level
*   valve3 controls flow out of tank2Level
*   seq determines the current state of the system
*   stopped prevents execution of commands

## Requirements
*   Tank1 Level shall be maintained at 0.05 m (start=h0, unit="m")
*   Tank2 Level shall be maintained at 0.05 m (start=h0, unit="m")
*   Experiment duration: 700 seconds (based on test harness button edges)
*   Report tank levels and valve commands for 700 seconds

## Behaviors
*   IF seq == StepState.FILL AND NOT stopped THEN valve1 = true ELSE valve1 = false
*   IF seq == StepState.TRANSFER AND NOT stopped THEN valve2 = true ELSE valve2 = false
*   IF seq == StepState.DRAIN AND NOT stopped THEN valve3 = true ELSE valve3 = false
*   When edge(startCmd) then stopped := false; end when;
*   When edge(stopCmd) then stopped := true; end when;

## Constraints
*   Tank1 Level is bounded between 0.05 m and 0.78 m
*   Tank2 Level is bounded between 0.05 m and 0.78 m

## Physical relationships
*   der(tank1Level) = (if valve1 then qFill else 0)/A1 - (if valve2 then qTransfer else 0)/A1
*   der(tank2Level) = (if valve2 then qTransfer else 0)/A2 - (if valve3 then qDrain else 0)/A2

## Scheduled commands
*   startCmd: when edge(startCmd) then stopped := false; end when;
*   stopCmd: when edge(stopCmd) then stopped := true; end when;

## Notes
The model is a simplified demonstration logic for a tank system. It includes parameters for tank volumes (A1, A2), liquid levels (h0, h1High, h1Low, h2Low), and flow rates (qFill, qTransfer, qDrain). The system uses boolean valves (valve1, valve2, valve3) to control the flow of liquid into and out of the tanks. The system has a discrete state machine (seq) that transitions between different states (IDLE, FILL, HOLD1, TRANSFER, HOLD2, DRAIN, HOLD3) based on the input commands (startCmd, stopCmd). The system uses timers (wait1, wait2, wait3) to introduce delays between states. The model does not include SHUT handling. The test harness provides button edges at 20, 220, 280, 650 and 700 seconds to trigger the state transitions. The equations for tank level changes are derived from the flow rates and tank volumes.
