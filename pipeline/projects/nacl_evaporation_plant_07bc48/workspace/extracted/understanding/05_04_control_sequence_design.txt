## Relationships
* sensors connector bundles measured process values
* actuators connector bundles automated valve, pump and thermal commands
* manual/isolation valves excluded from StateGraph actuator bundle (unless specifically stated in the ICD)
* Step6 creates concurrent branches Branch A and Branch B
* Branch A cools condensate in B6
* Branch B transfers concentrate from B5 (to B7)
* recovered condensate from B6 returns to B1
* cooled concentrate from B7 returns to B2
* controller.sensors.LIS_301 assigned from B3.level
* controller.sensors.QIS_502 assigned from B5.medium.Xi[NaCl]
* V9.open assigned from controller.actuators.V9
* HeatB5.Q_flow assigned from controller.actuators.T5_Heater (if true then 20000 else 0)

## Requirements
* Controller valve-group assignments shall follow CR-017. [current]  <CR-017>
* A join is satisfied only when both branches report completion.
* Automated valves fail closed and are not treated as modulating valves.

## Constraints
* B5 heater permissive: LIS-501 >= 0.05 m AND FIS-801 >= 0.10 kg/s.
* P1 permissive: LIS-701 > 0.02 m.
* P2 permissive: LIS-601 > 0.02 m.

## Behaviors
* If startEnable AND B3 available, the Initial state transitions with all automated valves closed and pumps/heaters/coolers off.
* If LIS-301 >= 0.13 m, Step1 action is V8=OPEN.
* If QI-302 >= 0.080 kg/kg, Step2 action is V9=OPEN.
* If LIS-301 < 0.01 m, Step3 action is V11=OPEN.
* If LIS-501 <0.01 m AND NOT V15, Step4 has no transfer actuator.
* If LIS-501 >=0.18 m, Step5 action is V12=OPEN.
* If QIS-502 >=0.180 kg/kg, Step6 action is B5_Heater=ON.
* If TIS-602 <=20 degC, Step12 action is B6_Cooler=ON.
* If B6 return complete, Step13 action is P2=ON + corrected B1 return valve group.
* If LIS-701 <0.01 m, Step7 has no transfer actuator.
* If LIS-501 <0.01 m, Step8 action is V15=OPEN.
* If TIS-702 <=25 degC, Step9 action is B7_Cooler=ON.
* If B7 return complete, Step10/11 action is P1=ON + corrected B2 return valve group.
* If A complete AND B complete AND time>2500 s, Join has no transfer actuator.
* Low discharge pressure alarm if PIS-901 < 0.8 bar(g) while running.
* Low discharge pressure alarm if PIS-1001 < 0.8 bar(g) while running.
