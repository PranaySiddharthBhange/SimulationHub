## Relationships
* central controller implemented as StateGraph-style sequential function chart
* sensors connector bundles measured process values
* actuators connector bundles automated valve, pump and thermal commands
* Manual/isolation valves excluded from StateGraph actuator bundle (unless specifically stated in the ICD)
* Step6 creates concurrent branches Branch A and Branch B
* Branch A cools condensate in B6
* Branch B waits for availability of B7
* Branch B transfers concentrate from B5 (to B7)
* B5 concentrate transferred to B7
* B6 returns to B1 (recovered condensate)
* B7 returns to B2 (cooled concentrate)
* controller.sensors.LIS_301 assigned from B3.level
* controller.sensors.QIS_502 assigned from B5.medium.Xi[NaCl]
* V9.open assigned from controller.actuators.V9
* HeatB5.Q_flow assigned from controller.actuators.T5_Heater (if true then 20000 else 0)

## Requirements
* Controller valve-group assignments shall follow CR-017.  <CR-017>

## Constraints
* B5 heater permissive: LIS-501 >= 0.05 m AND FIS-801 >= 0.10 kg/s.
* P1 permissive: LIS-701 > 0.02 m.
* P2 permissive: LIS-601 > 0.02 m.

## Behaviors
* If startEnable AND B3 available, then transition from Initial with all automated valves closed and pumps/heaters/coolers off.
* If LIS-301 >= 0.13 m, then Step1 action is V8=OPEN.
* If QI-302 >= 0.080 kg/kg, then Step2 action is V9=OPEN.
* If LIS-301 < 0.01 m, then Step3 action is V11=OPEN.
* If LIS-501 <0.01 m AND NOT V15, then Step4 has no transfer actuator.
* If LIS-501 >=0.18 m, then Step5 action is V12=OPEN.
* If QIS-502 >=0.180 kg/kg, then Step6 action is B5_Heater=ON.
* If TIS-602 <=20 degC, then Step12 action is B6_Cooler=ON.
* If B6 return complete, then Step13 action is P2=ON + corrected B1 return valve group.
* If LIS-701 <0.01 m, then Step7 has no transfer actuator.
* If LIS-501 <0.01 m, then Step8 action is V15=OPEN.
* If TIS-702 <=25 degC, then Step9 action is B7_Cooler=ON.
* If B7 return complete, then Step10/11 action is P1=ON + corrected B2 return valve group.
* If A complete AND B complete AND time>2500 s, then Join has no transfer actuator.
* A join is satisfied only when both branches report completion.
* Low discharge pressure alarm if PIS-901 < 0.8 bar(g) while running.
* Low discharge pressure alarm if PIS-1001 < 0.8 bar(g) while running.
* Automated valves fail closed and are not treated as modulating valves.
