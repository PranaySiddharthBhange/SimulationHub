Subject: Design Review DR-07 - NaCl Evaporation Bench
Document kind: correspondence

## Entities
* Controller -- control element
* StateGraph -- control model
* B5 heater -- heater
    - level permissive threshold: 0.05 m [approved]
    - flow permissive threshold: 0.10 kg/s [approved]
* LIS-501 -- level indicator switch
    - threshold: 0.05 m [approved]
* FIS-801 -- flow indicator switch
    - threshold: 0.10 kg/s [approved]
* P1 -- pump
* P2 -- pump
* source-tank -- tank
* Automated process valves -- valves
* K1 -- condenser
* legacy Modelica component -- model component
* evaporator -- process unit
* condenser -- process unit
* Junction volumes -- volume elements
* StandardWater -- physical variant
* WaterNaCl -- physical variant
* B7 -- cooling step

## Relationships
* Controller has topology StateGraph (sequential with a parallel split after evaporation and a join before cycle reset)
* B5 heater has permissive from LIS-501 (>= 0.05 m)
* B5 heater has permissive from FIS-801 (>= 0.10 kg/s)
* P1 requires dry-run inhibit from source-tank (source-tank level)
* P2 requires dry-run inhibit from source-tank (source-tank level)
* legacy Modelica component combines equations for evaporator (and condenser)
* StandardWater is baseline only for WaterNaCl (topology/control integration baseline only; intended physical variant remains WaterNaCl)

## Requirements
* P1 and P2 require dry-run inhibit from source-tank level. [approved]
* Junction volumes are mandatory where closed valve combinations could otherwise leave pressure/composition states undefined. [approved]
* Automated process valves are discrete and fail closed. [approved]

## Behaviors
* B5 heater permissive requires LIS-501 >= 0.05 m and FIS-801 >= 0.10 kg/s. [approved]
