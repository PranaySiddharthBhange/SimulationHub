## Entities
* exciting coil
* measuring coil
* useful-flux sensor
* leakage-flux path
* rectangular iron core
* air-gap
* left iron
* right iron
* lower yoke

## Relationships
* exciting coil supplies magnetic flux to rectangular iron core
* rectangular iron core contains air-gap
* air-gap contains measuring coil
* air-gap contains useful-flux sensor
* rectangular iron core contains leakage-flux path
* measuring coil measures flux
* useful-flux sensor measures flux
* leakage-flux path contains flux
* left iron supplies flux
* right iron supplies flux
* lower yoke supplies flux

## Requirements
* The exciting coil induced voltage |U| = 2*pi*f*N*|Phi| where f is frequency, N is number of turns, and |Phi| is flux.
* An electric ground and a magnetic ground shall both be present.

## Behaviors
* A positive RMS current-phasor magnitude ramp through the exciting coil produces a positive magnetomotive force N*I.
* The resulting total core flux follows the defined positive magnetic direction.
* The measuring-coil voltage has negative orientation relative to the useful air-gap flux.

## Constraints
* The rectangular iron core has a square cross section with side length 25 mm.
* The air-gap has a length of 1.50 mm.

## Physical relationships
* B = Phi / A (Flux density B is derived from flux Phi and cross-sectional area A)
* H = B / mu (Magnetic field strength H is derived from B using the applicable permeability mu)
* U = 2*pi*f*N*Phi (Induced voltage U in the exciting coil is given by the formula)
