## Behaviors
* If T1 reaches low level, then open the drain valve after 12 s. [approved]
* If T2 reaches low, then the next fill starts after 8 s. [approved]
* If during SHUT, then V2 and V3 stay commanded open until both low-level conditions are satisfied. [approved]
* If START occurs during SHUT, then it is ignored. [approved]
* If STOP is implemented as a latch, then it forces all valves closed; START clears it. [current]
