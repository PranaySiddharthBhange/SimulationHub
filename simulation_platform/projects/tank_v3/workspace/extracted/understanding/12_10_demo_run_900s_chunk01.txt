*   If controller_state == WAIT_AFTER_FILL, then wait for 8 seconds (page 21)
*   If controller_state == WAIT_AFTER_FILL, then wait for 7 seconds (page 22)
*   If controller_state == WAIT_AFTER_FILL, then wait for 6 seconds (page 23)
*   If controller_state == WAIT_AFTER_FILL, then wait for 5 seconds (page 24)
*   If controller_state == WAIT_AFTER_FILL, then wait for 4 seconds (page 25)
*   If controller_state == WAIT_AFTER_FILL, then wait for 3 seconds (page 26)
*   If controller_state == WAIT_AFTER_FILL, then wait for 2 seconds (page 27)
*   If controller_state == WAIT_AFTER_FILL, then wait for 1 second (page 28)
*   If controller_state == WAIT_AFTER_FILL, then wait for 0 seconds (page 29)
*   If controller_state == TRANSFER_T1_T2, then open valve2 (page 180)
*   If controller_state == TRANSFER_T1_T2, then open valve3 (page 180)
*   If controller_state == PAUSED, then stop all valves (page 220)
